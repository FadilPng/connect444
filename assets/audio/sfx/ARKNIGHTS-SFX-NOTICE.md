The upstream README states educational use. No permissive license granting use/redistribution in another game was found at its repository root. A public repository and attribution do not themselves grant permission. Obtain the necessary permission or replace these recordings before a public/commercial release.

`arknights-sfx-sources.json` maps all output paths to their exact pinned upstream sources and includes processing parameters and SHA-256 checksums. Cues were shortened where appropriate, normalized for gameplay, given short end fades and encoded as real 44.1kHz stereo MP3 files at 128 kbps.

This add-on deliberately includes no BGM and no files for the protected cards: purge, magnetic, heavy, bomb, gravity, flip, bottom, void, superbomb. No HTML, CSS or JavaScript files are included in the asset ZIP.
